# 生活手记面板

启动已有本地服务后打开 `/life`。独立运行时默认是 `http://127.0.0.1:5421/life`，需要本机配置中的 **adminToken**；绑定令牌不能访问管理面板。实时 QQ 桥接适配使用它原来的控制台管理令牌和端口，无需再启动前端进程。

页面、样式和插画均从本机加载，无 CDN、无遥测、无前端构建步骤。首次输入令牌后仅保存在当前浏览会话的 sessionStorage；退出可清除。链接可带 `#token=...` 完成同一本地服务的登录，页面读取后立即移除片段，分享链接前仍应检查地址。默认回环监听没有改变。

## 已提供

- 今天 / 明天 / 历史日期切换，最多查看前后一年。
- 真实日程与约定合成时间线。当前计划、已自述进行、已确认、跳过、已过时段未确认分别标记。
- 持续事项、当前进度、下一步打算，不展示编造的百分比。
- 私聊约定、时长、取消状态和已过时刻但未确认兑现的约定。
- 记录来源、证据、确认时间、日程变更与修订历史。
- 单条记录细节纠正、撤回、恢复。每次须填原因并校验版本；旧内容留档，旧页面不会覆盖新记录。
- 角色与设定为当前值展示。情绪系统、角色生活配置包尚未实现，不用假数据占位。

浏览未来日期只显示模板预览与已保存约定，不调用 Agent、不生成日期记录、不启动每日规划。历史无记录的日期保持空白。持续事项展示的是当前记录，页面明确注明不随所选日期回溯。

纠错只针对所选日程记录的具体细节，不调整时间、活动状态或持续生活线中的固定事实；要改约定继续使用普通聊天，避免假造“模型已同意”。撤回使该记录回到未确认计划，可从同一条时间线恢复，原证据和每次操作都保留。

## 接口

管理令牌鉴权：

- GET `/life/api/bindings`：可管理的实例列表，不含令牌。
- GET `/life/api/view?binding=demo&date=2026-01-10`：有限的展示数据。
- POST `/life/api/records/revise?binding=demo`：`{date,slotId,expectedVersion,action,reason,details?}`；action 是 correct / retract / restore。

返回版本冲突时刷新后核对，不能自动重试覆盖。读视图不会写入原存储。普通会话绑定令牌、Agent 权限不能使用管理端接口。

## QQ 快捷入口

实时桥接已接入 `/生活`、`/生活 明天`、`/生活 昨天`、`/生活 YYYY-MM-DD`、`/约定`。沿用白名单与管理员权限；群聊只显示公共生活状态，私人约定只在私聊返回。直接读取本地数据，不启动模型回合。

独立核心提供 `parseLifeCommand` / `formatLifeReply`，其他框架可在原权限检查后复用。独立 HTTP 运行时不自带 QQ 收消息插件，不能声称仅启动网页就接管 QQ。网页适配手机屏幕；手机不能把电脑的 127.0.0.1 当作电脑地址，第一版手机入口使用 QQ 指令。

## 验证边界

自动测试使用临时 JSON 和模拟网关；浏览器交互在独立示例数据中验收，覆盖登录、日期切换、纠错、撤回、恢复和桌面/手机布局。正式数据验收只读，不为展示编造经历。界面插画是装饰，不是实际活动截图。
