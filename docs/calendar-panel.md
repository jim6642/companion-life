# 生活日历与特别纪念

当天记录是面板首页，生活日历是日期索引，点击日期进入当天记录；生活方向只管理后续活动素材，不覆盖宿主人设。浏览月份不生成日程、不调用模型，显示一年以内的日期。

- 管理面板可添加、编辑、撤回特别纪念，标题40字、说明240字，每天最多8件手动纪念。修改用版本校验防止覆盖，旧值保留在修订记录中。撤回是软删除，存档仍在本地文件。
- 普通日程只显示记录标记，不自动变成纪念。
- 已成功送达且完成的虚拟生活自述，可在现有 lifeEvents.details 中带 milestone 标题，逐字引用本轮 evidence。沿用既有证据检查，不增加模型调用。日历标明“聊天自述”，不代表现实能力得到独立验证；真实插件安装建议由用户手动确认。
- 手动纪念属于面板资料，不自动注入日常聊天，不主动发送消息。聊天纪念沿用已有生活细节检索。
- 聊天自述纪念通过原事件详情纠正或撤回；手动纪念在日期详情中编辑。历史事实与计划仍分开显示。

管理 API（需管理令牌）：GET /life/api/calendar?month=YYYY-MM；POST /life/api/milestones，字段 date/title/note，新建省略 id，编辑必须 id/version，action 为 save 或 retract。所有接口沿用本地鉴权及实例隔离。

暂不做法定节假日数据、每年自动重复周年提醒，也不保证模型每次都会主动识别有意义的纪念。
