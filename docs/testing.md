`npm run check` 执行隐私规则扫描、所有 JavaScript 语法检查、Node 内置测试，无需登录或付费 API。

## 真实模型验收（不能用模拟测试代替）

在专用测试会话按顺序问早餐、再问一次、重启运行时再问。检查模型实际调用 `life_propose`，再看 `life.json` 中 delivery=success 的来源。刻意令发送失败，确认没有新经历；令存储失败，确认只收到一次消息。最后验证原白名单拒绝、群聊未 @ 不触发、引用发送者、切角色、文字发送。

模型可能不调用工具，可能输出不符合证据要求，可能发生语义矛盾。只有这些真实观察通过后，才能把对应宿主标为“实测兼容”。发布的 README 不能将协议模拟测试当作真实 QQ 验收。

## 本地打包

`npm run release` 先检查再生成 tgz、SHA-256、文件清单。建议在包含空格的新路径解压，运行 demo/check/init/doctor/start，核对无私有配置、无旧项目依赖。这个操作不会新建远程仓库或上传文件。

第一次对外发布前还需手工核对打包文件列表、文档截图和 Git 暂存区；扫描器只覆盖常见账号、机器路径、凭据等规则，不是完整的秘密检测器。
